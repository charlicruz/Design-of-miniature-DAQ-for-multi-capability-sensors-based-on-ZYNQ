# Design-of-miniature-DAQ-for-multi-capability-sensors-based-on-ZYNQ


The GitHub project includes the following main components:

Folders:
Hardware: Files related to the hardware design for DAQ project. 

IoT_readout: Files associated with the Internet of Things (IoT) component of the project developed in LabVIEW code: sensor data readout executable or configuration files.

Software: Application code for the TENGS readout

Videos: demonstration  explaining the project's setup, use, or functionality.
