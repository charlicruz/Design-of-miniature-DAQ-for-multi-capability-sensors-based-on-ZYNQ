# Design-of-miniature-DAQ-for-multi-capability-sensors-based-on-ZYNQ


This repository provides the supplementary resources associated with the corresponding research article. It includes the Zynq hardware bitstream, C-based acquisition software for TENG sensors, a LabVIEW-based IoT readout application, and demonstration videos showing the experimental setup and system operation. The GitHub project includes the following folders:

**Hardware**: Files related to the hardware design. 

**Software**: Labview code for data acquisition.

**IoT_readout**: C software for TENG sensors.

**Videos**: Two demonstration videos for describing the system operation and the experimental setup.

These materials support the implementation, validation, and reproducibility of the proposed miniature data-acquisition platform.
